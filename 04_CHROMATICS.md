# Computational Chromatics
State-responsive digital color field C(x,y,t,s;theta), using established OKLCH/sRGB, gamut mapping and accessibility metrics. Color can encode graph proximity, intent and state; not decorative gradients only. Implement pure deterministic color transforms, role constraints, sRGB fallback, contrast checks (WCAG AA 4.5:1 normal text and 3:1 large text), non-color state cues, reduced flashing and motion. Treat HDR/wide-gamut as optional capabilities. Experiments: reproducibility, gamut mapping, semantic consistency, contrast violations caught by negative controls, light/dark mode.
