# Custom Computational Dynamics Runtime
Standalone library, no DOM or React dependency. Fixed timestep, seeded deterministic event order, declared numerical tolerance. Use graph springs/dampers: m_i q''_i = -grad_i V(q) - c_i q'_i + f_i(t), with V = sum_edges k/2*(distance-rest)^2 + boundary penalty. Implement stable semi-implicit Euler or velocity Verlet, positive masses, bounded impulses/displacements, damping, NaN guards, performance budgets. Discrete event field phi_next=phi+alpha*graphLaplacian(phi)-beta*phi+input; choose stable coefficients.

Typed semantic event -> dynamics impulse -> spatial projection + chromatic projection + optional note mapping. Example playful event makes interface briefly pink and plays notes only after user gesture; it must NEVER trigger real clicks, purchases or form submissions. Respect reduced motion and mute. Test same seed/events -> same quantized trace, convergence, bounded energy, no NaNs, replay, stress dt, input ordering, no side effects. GPU/WASM optional and not deterministic oracle.
