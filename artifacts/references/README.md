# Visual reference evidence

This directory contains 36 measured family/display cases from the deterministic visual replay summarized in [`../reports/visual-summary.json`](../reports/visual-summary.json). Across these cases, the recorded pixel delta is 0. Each case directory includes the original baseline, replay, diff, manifest, and accessibility evidence copied byte-for-byte from the measured run.

These images show self-reference fidelity between the measured baseline and replay; they do not establish aesthetic superiority. Original failed runs remain retained in the separate delivered evidence archive. File hashes and sizes, case IDs, and the source summary hash are recorded in [`../reports/github-reference-index.json`](../reports/github-reference-index.json).
