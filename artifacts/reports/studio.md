# Studio implementation

Owned application files: `apps/web/app/Studio.tsx`, `apps/web/app/globals.css`.

The client uses the actual semantic graph, six `generateSurface` composition solvers, React renderer, chromatics field, fixed-step dynamics world, and three-step selection-to-artifact performer pipeline. No remote model is connected. The companion is visibly labeled local, simulated and extractive. Authored demo fixture provenance and inferred intent evidence are visible.

Implemented controls include protected URL interpretation and plain fallback, three fixtures, family and seed regeneration, light/dark reading canvas, actual ResizeObserver canvas dimensions, input/pixel-ratio/reduced-motion facts, graph visualization derived from semantic edges, a user-triggered 240-tick event, gesture-gated optional WebAudio, passage context, cited artifact storage, close/reopen, source replay and downloadable reconstruction JSON.

Version-1 workspace validation checks graph, artifact digest and version-2 artifact surface manifests before restoration. Unknown versions, invalid JSON, damaged digests and incompatible manifests visibly recover to a clean workspace. Query parameters control graph/seed/family while saved artifacts remain available for the cold-reload journey. Source text is rendered as text through the adapter; no fetched HTML is injected.

Text enlargement uses an observed 16px font probe, a smaller logical display passed to the pure solver, and a corresponding canvas scale. Region content counter-scales to prevent multiplying enlarged fonts twice; normal percentage width already accounts for CSS zoom. Browser verification remains necessary before asserting that this satisfies the text-zoom gate.

Verification so far: `npx tsc --noEmit -p apps/web/tsconfig.json` passed. The first production-build React-19 useRef initialization issue was corrected by supplying explicit `undefined` initializers. Full production build and browser matrix are being run by the integration/browser workers; this report does not claim those have passed.

Exact event-world history persistence/replay is integrated through `worldManifest` / `replayWorld`, including event history, initial world options, target tick and trace hash. Both Workspace and version-2 SurfaceManifest include dynamics and inferred intents. A restored world is installed before a matching reconstruction record can be persisted, preventing initial mount state from overwriting saved history. Replay IDs resume after the highest saved local event suffix. Source/seed/family replay adapts the surface to the current display; it does not claim a different current viewport reproduces the original geometry.

Initial browser functional run passed fixture/API/fallback, artifact close/reopen/reload, seed/family/event/audio gesture controls and download. It exposed text zoom width over-expansion; the content percentage width was corrected. Initial320px matrix cases passed zero-pixel deterministic recapture, action target sizing, CSS contrast and physics. Resource-title vertical overflow and three axe visible-label mismatches were found and fixed. A full rerun of the updated production bundle is pending; these initial results are diagnostic evidence, not a final pass claim. Independent Playwright probes with the latest stylesheet verified zero region vertical overflow at320px, and at390px/200% text verified document width exactly390px, no region beyond the horizontal viewport, and zero region vertical overflow. These probes injected the latest stylesheet into the preceding production bundle; final integration still requires the newly built bundle.

The final artifact shelf uses the pure `apps/web/lib/artifacts.ts` append helper inside a functional React update. The next ID uses the maximum retained suffix for the specific source artifact rather than the capped list length. This prevents duplicate IDs after51 saves and avoids stale closure collisions on rapid asynchronous saves. `tests/artifact-store.test.ts` reproduces52 saves, asserts50 unique retained artifacts and checks the JSON-round-tripped workspace through full conformance validation. The original length-based implementation failed with49 unique IDs; the corrected implementation passes. Evidence is preserved in `artifact-store-red.txt` and `artifact-store-green.txt`. Both root and application TypeScript checks pass after this correction.

Manifest downloads contain the exact signed version-2 manifest without adding envelope fields, so the downloaded JSON remains acceptable to `replayManifest`.

All typography now uses locally bundled, licensed and checksum-recorded font files under `public/fonts`: Infinite Sans aliases Liberation Sans regular/bold; Infinite Serif aliases Liberation Serif regular/italic; Infinite Mono aliases Liberation Mono; Infinite Symbols aliases DejaVu Sans as the explicit symbol fallback. CSS waits for these local fonts with `font-display:block`, and the browser harness awaits `document.fonts.ready` before recording. This removes operating-system font selection and missing-symbol differences from recapture inputs.

Passage-less sources have an explicit empty-context message and a disabled global Come here control. The companion and its save control require an actual selected Text node; no reachable source passage means no advertised context creation.
