# Reproducible computational experiments

Run `npm run experiments` from the project root. The CLI prints a deterministic result digest and hypothesis status vector; elapsed runtime, build-file byte counts, host environment, git commit, dirty state, and tested source SHA-256 are separate run metadata. Every execution writes a new timestamped JSON file; earlier failures are retained. `artifacts/experiments/latest.json` and `artifacts/reports/research.md` represent the most recent run only.

The preregistration at `experiments/preregister.json` was saved before SDK results and contains H1–H7, seed ranges, six viewport definitions, independent oracles, metrics and explicit falsification thresholds. Each run records its independent SHA-256. Threshold changes require a versioned new registration; do not rewrite thresholds to match outcomes. The initial matrix used three stress dimensions in place of required mission dimensions. Original registration and timestamped results remain intact. `experiments/preregister-amendment-1.json`, saved before the corrected run, documents this mismatch and specifies the exact required six dimensions plus a containment-edge response test. Each subsequent run records both registration SHA-256 values.

`experiments/oracles.ts` independently calculates W3C contrast from hexadecimal sRGB, geometric feasibility, tree/spatial structural signatures and Pareto dominance. SDK hashes, contrast functions and signatures are measured separately and are not used as their own correctness oracle. Full-content SHA-256 includes seeds: 1000 unique hashes does not mean 1000 structural designs or 1000 usable interfaces. Structural signatures characterize tree shape and ordinal region relationships, with subpixel perturbations suppressed; they remain a limited computational equivalence relation, not a perceptual judgment. The layout metric vector uses SDK proxies and gives no validated aesthetic score.

The six-family × six-display matrix checks finite positive regions, horizontal viewport containment, vertical scrolling, non-overlap, exact semantic coverage, semantic focus order, supported required actions and action target dimensions. These checks concern generated layout regions, not actual DOM text clipping, keyboard execution or accessibility-tree quality. Browser evidence must establish those additional facts.

The one-edge test deliberately adds a `references` edge. It measures response and rechecks capabilities; no response is required by its preregistered threshold. A renderer may ignore that edge. Results therefore cannot support a broad claim that all semantic changes influence layout. The amendment separately rewrites one containment edge endpoint from one Section parent to another for a Text target. An independent tree traversal checks the exact new parent, structural signatures must change for all families, and the semantic-lane workbench must change geometry. The original references-edge result is still reported separately.

The color test checks 1200 field cases spanning 200 seeds, both modes and three event states, plus high-chroma gamut inputs. Independent WCAG normal-text contrast gates use 4.5:1; no large-text exemption is needed. Negative controls use identical/low-contrast colors. Physics checks include 100 seeded three-node worlds, equal-tick event ordering, batching, damping, zero-force equilibrium, reduced motion, invalid inputs, bounded work and a 64-node stiff/low-mass/high-degree stress case. Quantized snapshot comparisons are exact for this runtime; cross-engine reproducibility has not been established. The runtime has no semantic-action callback, and the harness grants no external authority.

Performer tests exercise a deterministic five-operation cited-artifact pipeline and reconstruct its trace. Deliberately incompatible schema IDs, malformed runtime input, dishonest output, absent authority and attempted effect escalation must be rejected, including before prior operations execute. Static TypeScript compatibility complements these runtime checks; the incompatible-schema experiment intentionally enters through a widened call signature to test rejection of dynamically received operations.

NASA, restaurant and repository fixtures are local authored demonstrations. Domain classification is checked against independently known research/menu/repository source content. Intent evidence must reference existing graph identities or source content. These three examples do not establish real-web generalization. The restaurant form is detected without receiving submission capability.

Browser agent evidence is expected at `artifacts/reports/visual-summary.json`. H6 must remain pending until available. A repeated screenshot from the same seeded input can establish reproduction fidelity. It cannot establish improved similarity to an independently chosen target or human aesthetic quality. Report those conclusions separately, retain failed controls and real browser failures, and do not call a self-baseline an independent design target.

Replay a self-contained manifest with:

```sh
npm run experiments -- --replay artifacts/experiments/replay-manifest.json
```

The replay verifies independent fixture, graph and regenerated output SHA-256; it rejects changed seeds, graph content or fixture bytes. The manifest includes source HTML, graph, grammar version, seed, family and display so it can reconstruct without a server or persistent app state. The repository source hashes in each run identify the actual working implementation even while the recorded git commit predates uncommitted development.

Fetch established methodological references with `python experiments/fetch-bibliography.py`. It keeps inherited HTTP(S) proxy variables, verifies TLS, bounds transfer size/time and reads only public URLs. The captured bibliography records retrieval timestamps, original URLs, status, byte length and SHA-256. W3C WCAG 2.2, CSS Color 4, numerical integration/diffusion and runtime schema methods are existing work. This project does not claim those methods as novel science. It tests a particular implementation and combination, not theoretical novelty or statistical significance.
