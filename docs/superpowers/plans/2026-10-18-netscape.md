# Netscape Infinite Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or executing-plans, with independent module implementation in parallel under the session's explicit parallel delegation instruction.

**Goal:** Ship a functioning deterministic morphogenesis SDK and its complete Netscape Infinite application, with reproducible acceptance evidence.
**Architecture:** Source-first ESM monorepo. Core is the shared typed boundary; color and dynamics are framework-independent. A Next.js app consumes a React adapter and protected public-resource ingestion.
**Tech Stack:** TypeScript, Node >=22, Next.js, React, Playwright, Node test runner, tsup.
**Spec:** `docs/superpowers/specs/2026-10-18-netscape-design.md`, `docs/CONTRACTS.md`, supplied numbered files.

## Global Constraints

- No dependency on retired Golden Surface; no private services needed.
- C-001–C-012 are normative; constitutional version and enforcement revision differ.
- Effects are pure/local state/external read/external mutation; no silent escalation.
- No external mutations, publishing or deployment without explicit authority.
- Reproduce from canonical inputs, seed, grammar version, display, fixture hash and tick.
- Test displays: 320×568, 390×844, 768×1024, 900×390, 1440×900, 1920×1080.
- Contrast normal text >=4.5:1; targets >=44 CSS pixels; text readable with vertical scroll.

## Review Focus

1. Crafted URLs, redirects and DNS answers must not reach private addresses.
2. Corrupt or old saved state must fail safely with visible recovery.
3. Many or long source passages must not overflow the viewport.
4. Same-tick reordered events must produce the same bounded trace.
5. Unsupported forms and checkout-like affordances must never become executable mutations.
