# Research Harness and Evidence
Pre-register hypotheses: H1 seeded grammar reproducible; H2 required capabilities preserved across display rewrites; H3 chromatic fields remain accessible; H4 physics bounded/stable; H5 typed performer compositions reject incompatible effects; H6 visual reference similarity improves without violating invariants; H7 semantic intents remain distinguishable in NASA vs restaurant fixtures.

Each experiment: ID, hypothesis, fixtures, environment, code commit, seed, independent oracle, metric, falsification threshold, actual result, failures, interpretation, next test. Compare multiple seeds and environments; separate simulated and observed data. Do not claim novelty or significance from one fixture.

Create `artifacts/experiments/*.json`, `artifacts/screenshots`, `artifacts/diffs`, `artifacts/reports`, and reproducible CLI scripts. Track build sizes and runtime performance. Keep failing results after fixes.
