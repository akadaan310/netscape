# @netscape/conformance

`createManifest(graph, surface, display, tick = 0, chromaticField = {}, dynamics?, intents?)` creates a detached version 2 reconstruction record. It binds the complete semantic graph through `graphHash` and every record field through `integrityHash`. `surfaceHash` separately identifies generated geometry. Manifest seeds accept the same safe-integer range as core generation. Version 1 manifests are rejected because they did not bind semantic source content or replay metadata.

`replayManifest(manifest)` validates the bounded schema, checks digests, regenerates the surface, and compares exact regions, executable actions, provenance, and constitutional clauses. Optional inferred intents must cite graph node IDs. Optional dynamics must share the manifest tick; replay integrates their original options and accepted events and checks their trace. Construction checks the dynamics snapshot schema and work budget without integrating it again.

These noncryptographic digests detect accidental corruption. A writer who changes source data and recomputes all digests can create another internally consistent record. The record does not authenticate provenance, execute semantic actions, or establish external truth. Palette values are bounded six-digit hex colors and retained exactly; this helper does not independently recompute a chromatic field from arbitrary host state.

`validateWorkspace(unknown)` is a total restoration guard: malformed JSON, unsupported fields, digest errors, invalid graphs, invalid selections, invalid optional state, and replay failures return false. Workspace version remains 1; optional `dynamics` and `intents` preserve runtime history and inferred context. Saved artifact manifests use version 2. Graph version `1` is accepted as the legacy spelling of `1.0.0`; other graph versions are rejected.

Limits include 50 artifacts, 1000 semantic nodes, 10000 semantic edges, 1 million aggregate node text/labels/evidence/metadata characters, and bounded strings/arrays throughout persistence. Dynamics uses its own node/edge/event/tick limits plus at most 20 million tick × (nodes + edges) work across an entire workspace and its artifacts. Run workspace validation at an untrusted restoration boundary, since actual dynamics reconstruction has a cost; normal typed in-memory persistence need not repeatedly replay from tick zero.
