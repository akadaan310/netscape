# Netscape Infinite

A working computational interpretation studio for public knowledge, built on an independent deterministic morphogenesis SDK. Bring a supported public URL or choose an authored NASA, restaurant or repository demo; generate six composition families, select source context, attach a clearly simulated local companion, and save cited artifacts for reconstruction.

```sh
npm ci
npm run dev
```

Open **http://localhost:3000**. No login, secrets or paid provider is required. For a production launch:

```sh
npm run build
npm start
```

The app interprets public content. It does not execute third-party forms or payments, embed arbitrary sites, or connect to a signed-in ChatGPT session. Public URL reads use an exact HTTPS allowlist with DNS pinning, bounds and explicit fallback. Authored fixtures work offline.

Browser runs preserve screenshots, diffs, accessibility snapshots, manifests and failures in timestamped artifact directories.

No public deployment has been performed. Read the final assessment for observed results and remaining limits.
